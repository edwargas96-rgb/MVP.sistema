# Life Energy Store — loja de promoções com pedido via WhatsApp

Projeto independente (não usa `packages/ui`). Vite + React 18 + TypeScript + Tailwind.

```sh
npm run dev:life     # na raiz do monorepo
npm run build:life
```

- Loja: `/#/` · Painel do dono: `/#/admin` (PIN padrão `1234`, trocar em Configurações)
- Dados em `localStorage` do navegador (sem backend nesta fase).
